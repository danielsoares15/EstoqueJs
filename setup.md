# Guia Rápido de Instalação (Setup)

Consulte a documentação completa no arquivo [README.md](./README.md).

### Passo a passo rápido:

1. **Backend**:
   ```bash
   cd backend
   npm install
   cp .env.example .env
   npm run dev
   ```

2. **Frontend**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```

3. **Popular produtos de demonstração**:
   ```bash
   node scripts/popular_produtos.js
   ```

4. **Login inicial**:
   - Usuário: `admin`
   - Senha: `admin`
